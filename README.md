# Optimizing User, Group, and Role Management with Access Control and Workflows

## Project Overview

This project is developed using the ServiceNow platform to manage users, groups, roles, and access permissions securely.

It helps project managers assign tasks to team members, control user access, and monitor task progress using workflows.

## Project Objectives

- Create and manage users and groups.
- Define roles and permissions.
- Implement Access Control Lists (ACLs).
- Restrict unauthorized access.
- Automate task assignments.
- Track task progress and status updates.

## Technologies Used

- ServiceNow
- Access Control Lists (ACL)
- Users, Groups and Roles
- Flow Designer
- Import Sets
- Update Sets

## Main Modules

1. User Management
2. Group Management
3. Role Management
4. Access Control
5. Workflow Automation
6. Task Management

## User Roles

| Role | Responsibilities |
|---|---|
| Project Manager | Create projects, assign and manage tasks |
| Team Member | View assigned tasks and update status |
| Administrator | Manage system configurations and permissions |

## Project Workflow

1. Project Manager creates tasks.
2. Tasks are assigned to team members.
3. Team members view their assigned tasks.
4. Team members update task status and work notes.
5. Project Manager monitors project progress.
